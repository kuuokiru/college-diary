# 📚 Электронный дневник ИМСИТ — Структура проекта

## 🗂 Что за что отвечает

```
college_diary/
│
├── 📁 config/                  ← НАСТРОЙКИ ПРОЕКТА
│   ├── settings.py             ← главные настройки (БД, язык, приложения)
│   └── urls.py                 ← адреса страниц сайта
│
├── 📁 journal/                 ← ОСНОВНОЕ ПРИЛОЖЕНИЕ (журнал, оценки)
│   ├── models.py               ← таблицы БД: Предмет, Группа, Занятие, Оценка
│   ├── views.py                ← логика страниц (что показывать пользователю)
│   ├── urls.py                 ← адреса страниц журнала
│   ├── admin.py                ← настройка панели администратора
│   └── migrations/             ← история изменений базы данных
│
├── 📁 users/                   ← ПРИЛОЖЕНИЕ ПОЛЬЗОВАТЕЛЕЙ
│   ├── models.py               ← модель пользователя с ролями (студент/препод/админ)
│   ├── views.py                ← страница списка пользователей
│   └── admin.py                ← пользователи в панели администратора
│
├── 📁 templates/               ← HTML-ШАБЛОНЫ (внешний вид страниц)
│   ├── base.html               ← основной шаблон (шапка, меню, футер)
│   ├── registration/
│   │   └── login.html          ← страница входа
│   ├── journal/
│   │   ├── home.html           ← главная страница
│   │   ├── schedule.html       ← расписание занятий
│   │   ├── journal.html        ← список занятий (для преподавателя)
│   │   ├── lesson_detail.html  ← страница занятия + выставление оценок
│   │   ├── lesson_add.html     ← добавить новое занятие
│   │   └── my_grades.html      ← мои оценки (для студента)
│   └── users/
│       └── list.html           ← список пользователей
│
├── 📁 static/css/
│   └── style.css               ← СТИЛИ (цвета, шрифты, внешний вид)
│
├── manage.py                   ← ЗАПУСК ПРОЕКТА (python3 manage.py runserver)
├── db.sqlite3                  ← БАЗА ДАННЫХ (все данные хранятся здесь)
├── requirements.txt            ← список библиотек Python
└── create_demo_data.py         ← скрипт создания тестовых данных
```

## 🔧 Как что редактировать

| Что хочу изменить | Какой файл открыть |
|---|---|
| Цвета, шрифты, внешний вид | `static/css/style.css` |
| Текст на странице входа | `templates/registration/login.html` |
| Меню навигации | `templates/base.html` |
| Главная страница | `templates/journal/home.html` |
| Расписание | `templates/journal/schedule.html` |
| Страница оценок студента | `templates/journal/my_grades.html` |
| Добавить новое поле в БД | `journal/models.py` или `users/models.py` |
| Логика работы страниц | `journal/views.py` |
| Адреса страниц | `config/urls.py` и `journal/urls.py` |
